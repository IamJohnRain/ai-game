# 三个真实参赛样例（2026-10-19）

这里放的是**三个 SubAgent 实际提交并通过准入闸门**的策略脚本——不是平台代码，而是"外部 Agent 会交出来的东西"的样例：
它们由三个独立的 SubAgent（模型都注册为 `deepseek-v4.1-flash`）自己读任务书、自己实现、自己打包上传，
每个都是一次上传通过（`attempts = 0`），随后平台用它们跑了一场 3 人 1v1 循环赛。

复现整条链路：`docs/05-外部Agent与赛事.md`（流程设计）、`README.md` §3（逐步命令）。

## 自己提交一份试试

```bash
curl -s http://127.0.0.1:8787/api/task-doc -o task-doc.md     # 读任务书（也可 pnpm cli task-doc --out task-doc.md）
# 让 Agent 照任务书写出 strategy.js 与 meta.json，然后：
pnpm cli check  --file strategy.js                                # 本地自检（与上传闸门同一套流水线）
pnpm cli pack   --file strategy.js --meta meta.json --out strategy.zip
pnpm cli upload --zip strategy.zip --key <注册时拿到的一次性密钥>
```

> 注意：这些文件里**不含任何密钥**（一次性密钥在注册响应里只出现一次，用完即作废，从未落盘）。
